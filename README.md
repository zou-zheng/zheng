# 铭惠学习 · 初中全科学习伴侣

这是一个可直接运行的学习 App 前端原型，覆盖了“学 — 练 — 改”的核心体验闭环：

- 首页学习仪表盘：今日任务、连续学习、学习时长、掌握度和错题回炉
- 学知识：九大学科、年级/学期/教材版本切换、知识地图和学习路径
- 公式词汇：独立栏目按初一/初二/初三与九科筛选；每个非英语学科每个年级先提供10张公式、规律或答题表达卡，英语每个年级提供30个分级词汇、音标、例句，并内置单词和例句音频，离线也可朗读
- 闯关练习：跟随当前所选学科出题，每科 16 题题库按套自动抽取，每套固定 10 题；包含基础巩固与原创历年题型风格题，支持选择、填空、简答输入，完成后自动归档到闯关合集并开启下一套，不设套数上限
- 错题本：按学科归类、今日复习、重做入口
- 基础诊断：每科 5 道基础题，输出掌握度、薄弱题型和“先补基础/基础巩固/进入专项”路线
- 学情报告：综合掌握度、各科掌握度、近 7 天学习节奏、错误题型和明日建议
- 错题再练：按概念混淆、方法不会、审题遗漏等错误原因筛选复习
- 学科专项工具：英语听力范读、浏览器支持时的跟读评分、作文诊断入口；物理/化学/生物虚拟实验步骤；文科记忆卡片；基础自测独立抽取3题，完成后再选择是否进入10题闯关
- AI 分层提示：先提示、再提示一步、查看答案；拍题结果增加识别确认提醒，追问保留连续对话记录
- 我的：成长数据、勋章、学习热力
- AI 解题：文字题目输入、拍照/相册识题、答案、分步解析、3 套解题思路（基础法/方法法/验证法）、知识点定位跳转、低基础讲解卡、联网搜索来源、追问和错题保存入口
- 操作数据记录：匿名记录页面访问、选科筛选、答题、错题复习、AI 解题和英语朗读等关键行为，便于后续调整内容
- 使用浏览器 `localStorage` 保存年级、教材选择、星星、错题与学习进度；首次安装初始化为“小妹”，后续 APK 升级会保留已有学习记录，不会因版本号变化重置

## 启动

需要 Node.js 22.5+（使用内置 SQLite 记录操作数据）：

macOS 用户也可以双击 `启动铭惠学习.command`，首次运行会自动安装依赖并打开浏览器。

```bash
npm install
npm run dev
```

然后打开终端提示的本地地址。

## 接入联网 AI

AI 页面默认可以用离线示例演示。需要真实联网解题时：

1. 复制 `.env.example` 为 `.env`，填写 `AI_API_KEY`。当前默认配置为 DeepSeek；也可以将 `AI_PROVIDER` 改为 `openai` 使用 OpenAI。
2. 在一个终端运行 `npm run server` 启动 AI 接口和操作记录服务。
3. 在另一个终端运行 `npm run dev`，打开页面左侧的“AI解题”。

真实 Key 只放在服务端环境变量中，前端通过 `/api/ai/solve` 调用。服务端支持文字题目和 base64 图片题目，使用 Responses API 的图片输入与联网搜索工具，并把识别出的题目、答案、分步解法、不同解法、对应教材知识点和搜索来源返回给页面。DeepSeek 文字题目使用 `deepseek-v4-flash`，拍照识题使用 `deepseek-v4-flash-vision-exp`；点击“去学这个知识点”会跳转到对应学科的基础学习路径；没有 Key 时前端会自动回退到内置演示解析。

## 说明

当前版本是可交互的产品原型，内容数据集中写在 `src/main.js` 中，便于演示和快速改稿。后续接入真实产品时，可按原需求将数据拆到：

- Android：Kotlin + MVVM + Jetpack Compose / ViewModel + Room + Retrofit
- 服务端：Spring Boot / Node.js RESTful API
- 数据：用户、教材版本、知识点、课程、题库、学习记录、错题本、进度
- 同步：本地优先，在线时同步学习进度与错题状态

## 操作数据记录

运行 `npm run server` 后，服务端会自动创建 `server/data/minghui-learning.sqlite`，前端会为当前浏览器生成匿名 ID，并把关键行为写入 `user_events` 表。记录内容包括操作类型、页面、学科、年级、学期、教材版本和少量统计字段；不会上传姓名、题目图片、题目原文或答案原文。

APK 会先写入手机本地数据库，同时通过联网队列同步到服务端；断网时最多暂存500条事件，恢复联网后自动补传。服务端使用 `client_event_id` 去重，避免重复上传。后台页面位于 `/admin.html`，需要在环境变量中设置 `ADMIN_PASSWORD` 后登录，可查看匿名用户数、活跃趋势、学科使用、功能使用和单个匿名用户明细。

本地调试：复制 `.env.example` 为 `.env`，填写 `ADMIN_PASSWORD`，运行 `npm run server` 后打开 `http://127.0.0.1:3001/admin.html`。管理员统计接口为 `/api/admin/overview`，用户明细接口为 `/api/admin/events`；原来的 `/api/events/summary` 现在也需要管理员登录，避免日志被公开读取。

Railway 部署：在服务变量中设置 `ADMIN_PASSWORD` 和 `DATA_DIR=/data`，并给服务挂载持久化 Volume，挂载路径填写 `/data`。否则 SQLite 文件可能在重部署或实例替换后丢失。正式上线还应定期备份数据库、限制管理员密码权限，并按未成年人数据保护要求设置数据保留期限。
